## フォルダ構成
emoji-factory/
├── index.html        ... 絵文字一覧（検索・コピー・削除・初期化）
├── add.html          ... 絵文字を追加するページ
├── emoji-store.js    ... データの保存・取得をまとめた共通スクリプト（新規）
└── style.css         ... 共通スタイル（変更なし）
```

削除したもの: `config.php` / `api/*.php` / `sql/*` / `data/emoji.sqlite`

## 使い方

`index.html` をブラウザで開くだけで動きます。

初回アクセス時に、元の17個の絵文字が自動で登録されます。

## 仕様

- **保存先**: `localStorage`（キー名 `emojiFactory.v1`）
- **追加 / 削除 / 検索**: 以前と同じ操作で使えます
- **初期状態に戻す**: 一覧ページ上部の「初期状態に戻す」リンク（元の17個に戻ります）
- **255文字**を超える入力、空欄はエラーになります

## 注意点

- データは **そのブラウザ・そのPCの中にだけ** 保存されます。別のブラウザや別の端末とは共有されません。
- ブラウザの「サイトデータ／閲覧履歴の削除」を行うと、登録した絵文字も消えます。
- ページの場所（URL・ドメイン・ポート）が変わると、別のデータとして扱われます。
- `file://` で直接開いた場合、ブラウザによってはページごとに保存領域が分かれることがあります。
  一覧と追加ページで内容が食い違うときは、上記の簡易サーバー経由で開いてください。
- シークレット／プライベートモードでは、ブラウザを閉じるとデータが消えます。
